# 道路长度、端点与混合高亮

道路详情中的长度是 Census 源线几何的总长。双向分隔车道各自计入；分支和不同源段也保留。因此它不是单向驾车里程，也不等于起终点之间的导航距离。

`scripts/add_road_endpoints.py` 提供可重复使用的拓扑端点函数：先将道路所有线段精确 noding，查找 degree-one 开放端部。20 米内的微小间隙只有在两端切线相向时才消除端点标记，保留平行车道的真正终点、短分支和大间断。输出坐标保留源几何位置，不移动到猜测的路口。闭合道路可没有开放端点。

`import_roads.py` 已在源几何简化前调用该函数，并用完整城市 polygon 确定端点归属。每条 GeoJSON feature 保存 `endpoints`、`endpointCount`、`endpointGeometryBasis`，目录也保存端点计数。无法精确关联城市的端点不补猜最近城市。详情以“端点 1、端点 2…”显示位置，明确未指定行驶方向；地图覆盖外的全国道路起终点不在此列表内。

高亮集合由独立的 `roadSelections` 和 `selectedRoutes` 构成。道路各有显示颜色，公共交通保留机构颜色。点击目录项只添加或聚焦，切换视图、机构或区域不清空集合；底部提供单项移除、全部清空、全部聚焦。详情面板只对应当前关注项，关闭详情保留高亮。

每条道路请求独立取消；完成前不会清掉已有道路。移除、清空或卸载时中止对应请求，迟到结果不会重新加入集合。地图依据 `focusedRoadId` 决定是否移动镜头，较早道路请求晚于公交选择完成时不会抢走当前焦点。

公共交通长度与首末站定义见 [交通详情](transit-details.md)。道路与边界来源及处理规则见 [道路数据](road-data-sources.md)。
